# CodeAlpha Task 2 — NovaCalc Pro Scientific Calculator

A complete, responsive scientific calculator built with **HTML, CSS and vanilla JavaScript** for the CodeAlpha Frontend Development Internship.

## Features

### Basic calculator
- Addition, subtraction, multiplication, division
- Decimal numbers
- Parentheses
- Percentage
- AC / DEL
- Real-time display

### Scientific functions
- sin, cos, tan
- sin⁻¹, cos⁻¹, tan⁻¹
- log (base 10)
- ln
- √ square root
- x²
- x³
- xʸ
- eˣ
- 1/x
- absolute value
- π and e
- factorial

### Professional calculator features
- DEG / RAD angle mode
- Memory: MC, MR, M+, M−
- Ans (previous answer)
- Calculation history
- History persistence using localStorage
- Dark / light theme
- Keyboard input
- Responsive mobile layout
- No external libraries
- GitHub Pages compatible

## Examples

- `sin(30)` in DEG mode → `0.5`
- `sqrt(144)` → `12`
- `5!` → `120`
- `2^8` → `256`
- `log(100)` → `2`
- `ln(e)` → `1`

## Run locally

Simply open `index.html` in a browser.

For VS Code:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install/use Live Server if desired.
4. Open `index.html`.

No npm, Node.js, database or backend is required.

## GitHub Pages

Upload the project files to a repository, then:

**Settings → Pages → Deploy from branch → main → / (root)**
